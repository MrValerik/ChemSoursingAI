# Обновление сервера ChemSource AI

Используй только штатный скрипт из корня репозитория:

```powershell
.\deploy\update-server.cmd
```

Не воспроизводи вручную `yc start`, SSH, резервное копирование, миграции, Compose и
health-check, пока скрипт доступен и не сообщил об ошибке.

## Порядок работы

1. Прочитай корневой `AGENTS.md`.
2. Проверь `git status`. Скрипт принимает только чистую ветку `main`, совпадающую с
   `origin/main`.
3. Если есть незакоммиченные или неотправленные изменения, остановись и сообщи
   пользователю, что именно нужно зафиксировать или отправить. Не коммить автоматически
   без явного разрешения.
4. Запусти `.\deploy\update-server.cmd`.
5. Если скрипт завершился ошибкой, сохрани первую значимую ошибку и устрани причину.
   Не обходи проверки чистоты репозитория, резервного копирования, миграций или health-check.
6. После успеха сообщи:
   - полный развёрнутый commit SHA;
   - публичный URL;
   - результат backend и LLM health-check;
   - состояние контейнеров и таймера автоостановки.

Скрипт сам запускает остановленную ВМ. Команда обновления является явным разрешением на
запуск ВМ и не требует отдельного вопроса об остановке на время разработки.
