# Обновление сервера ChemSource AI

Используй только штатный скрипт из корня репозитория:

```powershell
.\deploy\update-server.cmd
```

Не воспроизводи вручную `yc start`, SSH, резервное копирование, миграции, Compose и
health-check, пока скрипт доступен и не сообщил об ошибке.

## Порядок работы

1. Прочитай корневой `AGENTS.md`.
2. Проверь `git status`. Скрипт принимает только чистую ветку `main`.
3. Если есть незакоммиченные изменения, остановись и сообщи пользователю, что
   именно нужно зафиксировать. Не коммить автоматически без явного разрешения.
4. Запусти `.\deploy\update-server.cmd`.
5. Разреши скрипту автоматически синхронизировать локальный `main` с
   `origin/main` и выполнить `git push origin main`. При конфликте не запускай
   ВМ: сообщи конфликтующие файлы и обсуди разрешение конфликта с пользователем.
6. Если скрипт завершился ошибкой, сохрани первую значимую ошибку и устрани причину.
   Не обходи проверки чистоты репозитория, резервного копирования, миграций или health-check.
7. После успеха сообщи:
   - полный развёрнутый commit SHA;
   - публичный URL;
   - результат backend и LLM health-check;
   - состояние контейнеров и таймера автоостановки.

Скрипт сам отправляет чистую ветку `main` и запускает остановленную ВМ. Команда
обновления является явным разрешением на `git push` и запуск ВМ.
