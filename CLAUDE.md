# ChemSource AI — правила для агентов

Постоянные правила проекта лежат в [AGENTS.md](AGENTS.md) — он единый источник
для Codex, Claude Code и любого другого агента. Прочитайте его перед работой:
там цели продукта, архитектурные границы, порядок проверок и выката.

Здесь продублировано только то, чего нельзя не знать до первой команды.

## Над проектом работает несколько сессий одновременно

Они друг друга не видят и делят один checkout репозитория. Отсюда три правила,
каждое из которых уже нарушалось с последствиями:

1. **Работайте в собственном worktree**, созданном от актуальной `origin/main`.
   Общий checkout — не рабочее место. Не ждите, пока в дереве появятся чужие
   правки: соседняя сессия могла начать минуту назад.
2. **Индексируйте только свои файлы, поимённо.** `git add -A`, `git add .` и
   `git commit -a` захватывают чужую незакоммиченную работу. 1 сентября 2026
   правки поиска из соседней сессии уехали внутрь чужого коммита про документы.
3. **Никогда `git reset --hard`, `git checkout .` и `git clean` в общем
   дереве.** 1 сентября 2026 такой `reset` уничтожил готовую правку реестра
   целиком — модель, миграцию, сервис и тесты. Свой worktree чистить можно.

## Минимальная проверка перед коммитом

```powershell
Push-Location .\backend
try { ..\.venv\Scripts\python.exe -m pytest } finally { Pop-Location }
npm --prefix .\frontend run build
```

Локальные тесты идут на SQLite, а прод работает на PostgreSQL: расхождения
диалектов набор не ловит. Готовую карточку проходите на боевом сервере сами и
убирайте за собой созданные тестовые записи.
