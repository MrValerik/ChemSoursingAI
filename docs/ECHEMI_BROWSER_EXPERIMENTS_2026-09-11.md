прохождения: `Result.VerifyCode=T001`, `Result.VerifyResult=true`; после каждого

устойчивого прохождения любых последующих CAPTCHA.

## Какие параметры действительно доступны

[Документация RuCaptcha](https://rucaptcha.com/api-docs/alibaba-captcha) описывает
вход внешнего решателя, а не собственный алгоритм получения валидного ответа.
В этом тесте страница сама формирует запрос проверки через свой SDK. Коллектор
читает контекст, проверяет его актуальность и связывает ответ с нужной попыткой;
он не генерирует и не повторяет подписанные HTTP-запросы вместо SDK.

В обоих успешных случаях получены:

- `sceneId`, `userId`, `userUserId`, `userCertifyId` из текущего `InitCaptchaV2`;
- `prefix` из адреса текущей инициализации;
- `apiGetLib` из script src;
- `userAgent` из браузера.

`verifyType`, `region`, `u_atoken`, `u_asig` не обнаружены и не подставлялись.
`requestInfo` отсутствует в наблюдавшемся встроенном варианте виджета.
`UserCertifyId` запроса и `CertifyId` ответа инициализации хранятся как разные
значения. Сетевой `InitCaptchaV2` использует региональный
`*.captcha-open-southeast.aliyuncs.com`; ответ содержит `CertifyId` на верхнем
уровне. Библиотека загружается с `o.alicdn.com`.

Значения параметров находятся только в памяти браузерного сервиса и очищаются
при следующей инициализации/навигации и завершении задания. История хранит наличие
полей, источники, локальный номер контекста, время и разрешённые коды ответа.
Токены, cookies, подписи и тела запросов не сохраняются в Git или диагностике.

## Повторная диагностика 14.09.2026

№70 (обычный поиск β-Арбутина) получил три `F001 / false` на главной странице
до ввода вещества. Контекст каждого повтора инициализирован, обязательные поля
присутствуют, конфликтов нет. Профиль и Chrome совпадают с №67. №73 с отдельным
пустым профилем на том же сервере также получил два F001. №72 не дошёл до сайта:
Chrome не запустился в отдельном диагностическом процессе без Xvfb; этот запуск
не считается отказом CAPTCHA.

По [документации Alibaba](https://www.alibabacloud.com/help/en/captcha/captcha2-0/user-guide/description-of-data-returned-by-the-client)
F001 означает отказ по правилам оценки риска. Конкретный признак этим кодом не
раскрывается. Смена профиля сама по себе отказ не устранила. Подтверждения, что
причина заключается именно в IP, заголовках или движении мыши, нет.

Обнаружен отдельный дефект воспроизведения: все 181 записанное движение ожидали
последовательного round trip CDP. При задержке браузера временные метки не
соблюдались: запись 2.4775 с фактически занимала 3.6–4.2 с, а в первой попытке
№73 — 11.453 с. Новая реализация `pointer_motion.py` интерполирует координаты по
прошедшему времени, пропускает устаревшие отсчёты и завершает движение на измеренном
конце дорожки. Хвост записи за исходным концом 280 px отбрасывается. Эта правка
устраняет накапливание задержки в коде, но сама по себе не доказывает устранение F001.
